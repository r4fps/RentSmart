# RentSmart - Sistema de Orçamento de Aluguel (R.M Imóveis)

Trabalho académico desenvolvido para a gestão e cálculo de orçamentos de locação imobiliária com geração de projeção financeira em CSV.

## 🚀 Funcionalidades

- Cálculo dinâmico do aluguer para **Apartamentos**, **Casas** e **Estúdios**.
- Aplicação automática de regras comerciais (adicionais de quartos, vagas e desconto para apartamentos sem crianças).
- Parcelamento da taxa contratual em até 5x.
- Exportação da projeção financeira de 12 meses para ficheiro `.csv`.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3
- **Conceitos:** Programação Orientada a Objetos (POO), Herança, Polimorfismo e Abstração (`abc`).
- **Módulos Nativos:** `csv`

## 📂 Estrutura do Repositório

- `main.py:` Código-fonte principal do sistema.
- `TRABALHO_2.pdf`: Relatório técnico com a fundamentação teórica, diagramas UML e fluxogramas.
- `projecao_aluguel.csv`: Ficheiro gerado automaticamente com a projeção de 12 meses.

## 🏁 Como Executar o Projeto

1. Certifique-se de ter o Python 3 instalado na sua máquina.
2. Abra o terminal na pasta do projeto.
3. Execute o comando:

```bash
python main.py
```
